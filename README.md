# Date Joke App

A tiny mobile/desktop joke site that asks **“Will you go on a date with me?”**

- On desktop, the **No** button runs away as the mouse reaches it.
- On mobile, touching **No** immediately moves it and cancels the tap.
- Choosing **Yes** opens a future date/time picker.
- The chosen pickup time is displayed on a confirmation screen.
- Optional email delivery is already wired for a Formspree endpoint in `index.html`.

## GitHub Pages

This repo is designed to be served directly as a static GitHub Pages site from `index.html`.

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

The site URL will be:

`https://di-main-ai.github.io/date-joke-app/`
